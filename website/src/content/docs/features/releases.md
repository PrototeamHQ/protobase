---
title: Releases
description: How Protobase is released and versioned, and what a release keeps working.
---

- [Releases](/reference/versioning/#releases): Every fix and feature is released when it lands, as packages and images of one version.
- [Version rules](/reference/versioning/#versions-below-10): Semantic versioning. Below 1.0 a minor version may break.
- [Bundles and runtimes](/reference/versioning/#bundles-and-runtimes): A runtime serves only bundles of a compatible version, and says why when it refuses one.
- [Plugins keep working](/reference/versioning/#plugins): Plugins target a plugin API that releases keep.
- [Runtime updates](/reference/versioning/#runtime-updates): Admins see whether the runtime has an update and start it from the app, when the host offers one.
