## Layout

### Page

The root of every page, and only the root.

| Prop | |
| --- | --- |
| `title` | Heading, and the page's name in the sidebar and breadcrumbs. Required. |
| `description` | A line under the title. |
| `actions` | Elements beside the title, such as a `ModalForm`. |

### Grid

Columns that collapse to one on a phone, or to two when the grid holds only `Stat`s. A child's `span` (1 to 4) makes it wider.

| Prop | |
| --- | --- |
| `columns` | 1 to 4; default 2. |
| `span` | Its own width when it sits in another grid. |

```tsx
<Grid columns={4}>
  <Stat label="Draft orders" resource="orders" filter="status = 'draft'" />
  ...
</Grid>
```

### Card

A box with a heading. Text and `Link`s inside it run together as paragraphs.

| Prop | |
| --- | --- |
| `title`, `description` | The heading. |
| `actions` | Elements in the heading. |
| `span` | Width in a grid. |

```tsx
<Card title="No orders yet">Create the first order from Orders; this page fills up as the team sells.</Card>
```

### Link

A link in text: `to` an address in the app, or an `href` that leaves it (`https:` opens in a new tab, `mailto:` in the mail app). Its text is its children.

```tsx
<Link to={{ kind: 'list', resource: 'invoices', filter: "status = 'overdue'" }}>Overdue invoices</Link>
```

| Prop | |
| --- | --- |
| `to` | An [address](/reference/layouts/#addresses). Inside a record, `{field}` in its key, filter or order is the record's value. |
| `href` | A link that leaves the app. A path in the app is refused when the config loads: give it as `to`. |

One of the two is required. A link to a resource or field the user cannot see is left out of their page.

## Data

### Stat

One number or value with a label. Exactly one of `value`, `resource` and `field`.

| Prop | |
| --- | --- |
| `label` | Required. |
| `value` | A fixed value. |
| `resource`, `filter` | Counts the matching records the user can see; the card links to that filtered list. |
| `field` | A field of the record, through relations (`plan.name`). |
| `format` | Instead of the view's [format](/reference/ui-config/#names-and-columns), such as `badge`. |
| `description` | A line under the value. |
| `span` | Width in a grid. |

```tsx
<Stat label="Delivered, not paid" resource="orders" filter="status = 'delivered' AND paid = false" />
```

### Table

The first records of a list, drawn the way the resource's list page draws them: its table, or one of the view's [list displays](/reference/ui-config/#list-displays) such as cards, with the same switch between them when the view has several. A row or card opens the record, and **View all** opens the list with the same filter and order. On a phone a view with a cards display opens in it, as one row of cards that scrolls sideways; a display the viewer picks is kept for them in the browser.

| Prop | |
| --- | --- |
| `resource`, `filter`, `sort` | Which records, in which order. `resource` is required; `sort` defaults to the list's. |
| `columns` | Field names for the table; default the view's list columns. |
| `limit` | How many records it shows; default 10. It has no pages: the rest are in the list. Before 0.13 this was `pageSize`, rows per page; rename it. |
| `display` | The display it opens in, such as `cards`; default the list's. |
| `title`, `description`, `actions` | The heading. |
| `empty` | Text when nothing matches; default "Nothing here yet.". |
| `span` | Width in a grid. |

```tsx
<Table title="Overdue invoices" resource="invoices" filter="status = 'overdue'" sort="issued_at" columns={['number', 'company_id', 'due_at', 'total']} limit={5} empty="Nothing is overdue." />
```

### RecordCard

One record and what is inside it: the one `recordKey` names (the key as the record's URL has it), else the first that matches `filter` in `sort` order. Its children and its heading `actions` work on that record.

| Prop | |
| --- | --- |
| `resource`, `filter`, `sort` | Which record. `resource` is required. |
| `recordKey` | A fixed record instead. |
| `title`, `description`, `actions` | The heading. |
| `empty` | Text when no record matches. |
| `span` | Width in a grid. |

```tsx
<RecordCard title="Biggest unpaid delivery" resource="orders" filter="status = 'delivered' AND paid = false" sort="total desc" actions={<Action name="markPaid" variant="primary" />}>
  <Field name="number" />
  <Field name="company_id.city" label="City" />
</RecordCard>
```

### CardRow

Up to `limit` records side by side, each a small card made from the children, which work on that card's record. The heading's `actions` do not have a record: use them for a `ModalForm mode="create"`.

| Prop | |
| --- | --- |
| `resource`, `filter`, `sort` | Which records, in which order. `resource` is required. |
| `limit` | How many; default 12. |
| `title`, `description`, `actions` | The heading. |
| `empty` | Text when nothing matches. |
| `span` | Width in a grid. |

### RecordRow

What a filter finds, the way a home page shows it: the filter's chips, as the list's filter panel names them, how many records match, the records as the cards of the resource's [cards display](/reference/ui-config/#list-displays) in one row, and **View all**, which opens the list with the same filter and order. The row scrolls sideways by touch, trackpad or its arrow buttons; only the cards near the view are drawn, and the records load through the list API in pages as it scrolls. Each card opens its record. A resource without a cards display gets cards of the title alone.

It follows the resource's view as its list page does. Of a resource whose view has [`listOf`](/reference/ui-config/#favorites), such as favorites, it shows the records the user's saved ones point at, as their own resource's cards, and **View all** opens the favorites. Of one whose view has [`searchesOf`](/reference/ui-config/#saved-searches), it shows a row for each of the user's saved searches, under its name or its filters, with the records new to them marked **New** and **View all results**, as their list page shows them. `filter` and `sort` do not apply to those two.

| Prop | |
| --- | --- |
| `resource`, `filter`, `sort` | Which records, in which order. `resource` is required; `sort` defaults to the list's. |
| `limit` | How many records it shows at most; default every one that matches. |
| `display` | The cards display whose cards it draws; default the view's first. |
| `title`, `description`, `actions` | The heading. |
| `empty` | Text when nothing matches; default "No … match.", with the view's plural. |
| `span` | Width in a grid. |

```tsx
<RecordRow title="For rent" resource="listings" filter="for_rent = true AND status = 'available'" sort="published_at desc" />
```

### Field

A label over a value of the record, formatted as on the record page: statuses as badges with the view's value labels, relations as the related record's name (linked), the view's prefix and decimals.

| Prop | |
| --- | --- |
| `name` | A field, through relations (`company_id.city`). Required. |
| `label` | Default: the view's label, else the name in words. `false` shows the value alone. |
| `format` | Instead of the view's [format](/reference/ui-config/#names-and-columns). |

### Progress

A bar for `value` out of `max`, with both numbers. It turns amber from 90%.

| Prop | |
| --- | --- |
| `value` | A number, or the name of a field of the record. Required. |
| `max` | A number or a field; default 100. |
| `label`, `span` | |

```tsx
<Progress label="Seats" value="seats_used" max="plan.seats" />
```

### Chart

Counts, sums or averages of the records that match `filter`, per value of a field or per hour, day, week, month or year of a date field, in a card. It reads [`:aggregate`](/reference/api/#routes), so only what the user may see is counted, and the grouped field needs an index ([scan guard](/reference/api/#safety)).

| Prop | |
| --- | --- |
| `resource`, `filter` | The records it counts. `resource` is required. |
| `groupBy` | A filterable field. Values, such as an enum, a boolean or a relation (named by the related record), are ranked bars or a donut, each linking to its records; a date or timestamp field is a bar or line per bucket, empty ones included. Required. |
| `type` | `bar` (the default), `line` for a date `groupBy`, `donut` for one of values. |
| `sum`, `average` | A numeric field each group adds up or averages, with its prefix, suffix and decimals, instead of counting. One of the two; a donut takes no average. |
| `granularity`, `range` | A date `groupBy`'s bucket, `hour` to `year` (default `day`), and how far back it reaches: `7d`, `30d` (the default), `90d`, `1y` or `all`. |
| `limit` | How many values it shows, the largest; default 10. |
| `title`, `description`, `actions`, `empty`, `span` | As on `Table`. |

```tsx
<Chart title="Orders by status" resource="orders" groupBy="status" type="donut" />
<Chart title="Revenue by customer" resource="orders" groupBy="company_id" sum="total" filter="status != 'cancelled'" limit={5} />
<Chart title="Invoiced per month" resource="invoices" groupBy="issued_at" granularity="month" range="1y" type="line" sum="total" />
```

Each value takes its colour from the view's `valueColors`, else an enum value's place among its values, from the [chart tokens](/reference/theme/#tokens). A chart whose field the user cannot read is left out of their page, and a field it cannot group or add up stops the server at startup.

## Behaviour

### Action

A button for a [named action](/reference/layouts/#named-actions) of the view, on the record around it.

| Prop | |
| --- | --- |
| `name` | The action's name in the view. Required. |
| `resource` | Outside a record: the resource whose view declares it. |
| `label` | Default: the action's label. |
| `variant` | `primary`, `secondary` (default), `danger` or `ghost`. |

### ModalForm

A button that opens a form in a dialog. `create` makes a record of `resource`; `edit` changes the record around it (or `resource` with `recordKey`), sending only the changed fields with the record's ETag. The editors are the record page's, and errors from the server show on their fields. It is not shown to a user who may not create or update, and it keeps only the fields they may write.

| Prop | |
| --- | --- |
| `mode` | `create` or `edit`. Required. |
| `label` | The button. Required. |
| `fields` | The fields of the form, writable ones only. Required. |
| `resource` | Default: the record's resource. |
| `recordKey` | Edit this record. |
| `title` | The dialog's title; default the label. |
| `values` | Sent with every create, such as `{ status: 'lead' }` or a parent's key. |
| `variant` | As for `Action`. |

```tsx
<ModalForm mode="create" label="Add lead" resource="companies" fields={['name', 'city', 'country_code', 'email']} values={{ status: 'lead' }} />
```

### Show

Its children while [`when`](/reference/layouts/#conditions) holds.

| Prop | |
| --- | --- |
| `when` | A condition. Required. |

```tsx
<Show when="orders.count = 0">
  <Card title="No orders yet">...</Card>
</Show>
```
