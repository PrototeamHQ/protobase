description: Tables an app's users add from the admin UI, by hand or from a file, and how a developer takes them over as code.

- [Tables defined in the database](/reference/user-tables/#tables-defined-in-the-database) (in development): An app can keep tables its users add in its own database, beside the resources in its code. Each one is served like any other resource, at its own address with its list, record page, search and API.
